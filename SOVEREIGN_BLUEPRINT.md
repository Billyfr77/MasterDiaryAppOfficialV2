## 🌌 1. The Trinity Philosophy
MasterDiaryOS is not a suite of apps; it is a **Closed-Loop Neural Organism**. Every action in one engine must improve the intelligence of the others.

### **The Brain: Neural Estimation Engine (Quote Builder)**
- **Role:** Strategic Genesis.
- **Goal:** To predict the future cost and time of a project with 99% accuracy.
- **Standard:** Visual, node-based estimation with real-time margin protection.

### **The Nervous System: Neural Workflow Architect (Workflow Builder)**
- **Role:** Temporal Logic & Rerouting.
- **Goal:** To translate the "Quote" into a "Live Execution Lattice."
- **Standard:** 8 geometric structures, Neural Surge visuals, Level 5 self-healing.

### **The Senses: Paint Diary (Field Sensors)**
- **Role:** Reality Validation.
- **Goal:** To capture the "Ground Truth" (Actuals) and feed them back into the Brain.
- **Standard:** Obsidian Glass UI, tactile dragging, real-time productivity scoring.

## 🔄 2. The Closed-Loop Protocols (Billion-Dollar Logic)

### **Protocol Alpha: The Genesis Pulse (Quote -> Workflow)**
- **Trigger:** Quote Approval.
- **Action:** The Workflow Builder consumes the Quote Scope. AI auto-architects the initial project lattice, pre-generating all `taskNodes` with the correct `plannedHours` and `crewSize` defined in the quote.
- **Impact:** Eliminates 100% of administrative setup time.

### **Protocol Beta: The Execution Surge (Workflow -> Diary)**
- **Trigger:** Project Launch.
- **Action:** Workflow `taskNodes` manifest as "Mission Cards" in the Diary's Resource Dock. Workers drag these onto the timeline to begin work.
- **Impact:** Perfect alignment between office strategy and site action.

### **Protocol Gamma: The Learning Loop (Diary -> Quote)**
- **Trigger:** Daily Save / Project Close.
- **Action:** The system compares `Actual Hours` (Diary) vs. `Planned Hours` (Quote). If a discrepancy is detected (e.g., "Prep" always takes 15% longer), the **Neural Prism** updates the **Quote Builder's** default rates.
- **Impact:** The software learns how to make the user more money automatically.

## 🚀 4. Execution Protocols for AI & Developers
1. **Never Break the Loop**: Every new node or data field must be accessible by all three engines via the `data.config` or `data.actuals` JSON objects.
2. **Atomic Edits**: When modifying logic, use `replace` with significant context to ensure edge-cases (like handles or filters) are preserved.
3. **Telemetry First**: Every simulation must output a `results.stats` object that the **Neural Strategist** (Copilot) can read.
