Overview
The MasterDiaryOS Intelligence Stack is a collection of modular, read‑only AI nodes that interpret, analyze, forecast, and contextualize project diary data.

These nodes:

do not modify existing data

do not interfere with existing AI features

do not alter schemas

do not generate nodes/canvas/workflows

only read data and output new structured intelligence blocks

Each node is optional, non‑blocking, and fully compatible with the current MasterDiaryOS architecture.

🧩 Node Index

🔐 Safety & Compatibility Rules (Global)
All nodes MUST:

operate in read‑only mode

be deterministic

be schema‑consistent

be optional and non‑blocking

degrade gracefully with missing data

All nodes MUST NOT:

modify diary data

modify tasks or workflows

generate nodes or canvas data

alter PRISM_CORE, CHRONOS, HUB_SYNC, DELAY

introduce required fields

break backward compatibility
