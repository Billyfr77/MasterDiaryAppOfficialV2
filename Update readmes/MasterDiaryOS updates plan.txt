2. Core Principles
Gemini must follow these principles:

Do not modify or remove existing node types.

Do not restructure the diary.

Do not change the manifest schema.

Only extend the system with new intelligence.

2.2 Grok‑Powered Intelligence
All reasoning must use Grok‑4 Fast Reasoning 1.

Automatically adopt future Grok models as they release.

Keep the NPE model‑agnostic and future‑proof.

2.3 Chronos‑Native
All new features must integrate with Chronos Time Hub.

3. Task Nodes (New Node Type)
Task Nodes represent work units that connect labour, equipment, materials, zones, and time.

3.1 Purpose
Tasks become the central operational unit of the diary.

3.2 Requirements
Task Nodes must:

Link to Chronos

Link to Zones

Link to Staff nodes

Link to Equipment nodes

Link to Material nodes

Track planned vs actual hours

Track planned vs actual cost

Track task‑level productivity

Track task‑level delays

Track task‑level drift

3.3 NPE Responsibilities
The NPE must:

Analyse task performance

Detect task bottlenecks

Predict task completion

Suggest optimal crew/equipment

Detect task‑to‑task dependencies

3.4 AI Chat Integration
Users must be able to say:

“Create a task for trenching in Zone A.”

“Assign Crew 2 to the fencing task.”

“Link the excavator to this task.”

The AI must generate node links that become Task Nodes.

4.4 AI Chat Integration
Users must be able to ask:
