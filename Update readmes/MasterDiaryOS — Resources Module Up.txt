MasterDiaryOS — Resources Module Upgrade README
Authoritative, Non‑Breaking Specification for Gemini 3 CLI
Upgrades ONLY the Resources Page (Personnel, Assets, Calendar, Map)
This document defines the enhancements required to elevate the Resources Module into a predictive, intelligent, cinematic command center — without modifying any existing workflow logic, job data, or system architecture.

All changes must be:

Additive

Backward‑compatible

Non‑destructive

Isolated to the Resources Module

Read‑only unless explicitly stated

Fully reversible

Respectful of existing naming and data structures

🌍 Scope of This Upgrade
This README applies ONLY to the following UI and data surfaces visible on the page:

Personnel List

Heavy Assets List

Project Calendar (Weekly View)

HR/Leave Entries

Budget View

Resource Allocator

Geospatial Map (Google Maps)

No other modules should be touched.
